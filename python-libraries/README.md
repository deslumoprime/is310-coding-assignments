# Data Entry Script for Shopping

**OKAY**

In hindsight, this was probably supposed to be created for adding actual artifacts digitally like books, music, movies, and stuff, but I didn't realize that. 

I had a lot of recipt data stored in Excel. I use this to automatically split expenses and track blame on Costco runs with friends, as it is easier logistically for the collective if bifurcation of money happens AFTER the run. 

As such, this script has only two fields: SKU and price.
